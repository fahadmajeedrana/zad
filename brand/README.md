# Zad al-Talib brand assets (revised)

Palette: Forest green #075B35 · Deep green #034326 · Gold #E6B83F · Cream #FFF9E9

Changes from the original kit:
- The crescent now sits inside the arch. Before, it sat on top of the arch's peak and blurred into a blob at small sizes.
- The Arabic and Urdu text is converted to vector paths (Amiri, the app's font). It looks the same everywhere and needs no web font.
- The banner tagline now reads "طالب علم کا زادِ راہ", to match the app header.
- New maskable icon with a full-bleed background and the mark inside the safe zone, so Android doesn't crop it.
- The icons use currentColor, so they follow light and dark themes, on a 24-unit grid. The settings gear is redrawn (the original path was broken).
- PNG exports: icon-192/512, icon-maskable-512, apple-touch-icon (180), favicon-32, logo-1024, banner-1600.
